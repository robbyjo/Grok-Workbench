QUICK START

From download
to your first task.

No separate Grok CLI installation.
Just the app and a project to work on.

Read the full guide ↗

  1. Download and open

    Choose the package for your platform above. On Windows, save Grok-Workbench-0.9.0-Portable.exe in a writable folder and open it. On Ubuntu, install the .deb. Mac builds are UNTESTED; read the platform notes before volunteering.

  2. Connect your Grok account

    Click Sign in to Grok above Settings. Complete Grok OAuth sign-in in your browser, or save an xAI API key in the app. Model requests need internet access and account access/billing.

  3. Open your project

    Use the + beside Projects to choose a local folder, then start a chat. Install Git and your project’s development tools for the workflows that need them.

  4. Try a small first task

    Send a prompt like this:

    Explain how this project is organized and suggest one small improvement. Wait for me before changing files.

    Respond to project-trust and tool-approval requests above the composer. Inspect any edits in Changes; use Stop turn to cancel.

A few things to know

Keep your workspace with you. Windows portable data lives in Grok Desktop Data beside the executable. Move both together. Encrypted API keys may need re-entry on another PC or Windows account. Linux and Mac use their system application-data folders; preserve those folders during manual updates.

Choose permissions thoughtfully. Terminals and project actions run with your user permissions. Approval choices control tool requests; Grok’s OS-level agent sandbox is unavailable on Windows. Agent isolation on Linux and Mac remains unvalidated. About isolation ↗
